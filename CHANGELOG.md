# Changelog

## 2.5.0 — 2026-09-10

### Изменено
- **Camera Focus (DOF) переделана**: глубина (Z, метры) -> editable ColorRamp в ноде `DOF FOCUS RAMP` -> variable-size blur. Резко в фокусе, плавное нарастание размытия по дальности; рампу можно править прямо в нод-эдиторе.
- **Мастер-грейд**: новый финальный грейд (яркость/контраст/насыщенность) поверх всего компа со своей маской.
- **Система масок**: у DOF, GLARE, MASTER GRADE и FOG появилась секция MASK — источники None / Ext node / Alpha / Depth / Luma, инверсия, мягкость краёв (px). Маска оборачивает эффект по схеме `Mix(fac=MASK, A=orig, B=effect)`.
- **Preview Mask**: кнопка в каждой MASK-секции показывает маску эффекта во viewer.
- Самопроверка после сборки печатает в консоль состояние всех масочных цепочек.

### Удалено
- **Atmospheric Blur** — заменён улучшенным DOF с рампой.
- **Cryptomatte** — фича и файл удалены.

### Исправлено
- **Color Match** не работал: синтаксическая ошибка (двойной except) и ноды Blender 5.2 — переписан с фолбэками нод, Strength теперь реально применяется.
- **Lens Distortion**: параметры в панели теперь синхронизированы с нодой (установка по точным именам сокетов).
- Выключение эффекта теперь удаляет его ноды из компа, а не просто перестраивает связи.

## 2.0.0 — 2026-08-31

### Архитектура
- Аддон разделён на 6 модулей: `core`, `shadow`, `compositor`, `materials`, `operators`, `ui`
- Чистая структура зависимостей без циклических импортов
- Каждый модуль: 188–1119 строк (вместо 3648 в одном файле)

### Возможности
- Послойный композитинг с автоматической сборкой нод
- Туман (fog) через unified mist-маску с per-layer контролем
- Атмосферный блюр по глубине
- Камерная глубина резкости (DOF)
- Glare / Bloom (Bloom, Fog Glow, Streaks, Ghosts)
- Дисторсия объектива и хроматическая аберрация
- Тени (Cast / Receive) с прокси-объектами
- Редактирование материалов (экспозиция, контраст, насыщенность, тон)
- 1-Click EXR рендер + сборка компа из файлов
- Drag & drop перестановка слоёв
- Compositor-панель в Node Editor
