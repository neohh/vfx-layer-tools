# Changelog

## 2.1.0 — 2026-09-01

### Совместимость
- Добавлен `blender_manifest.toml` для Extension Platform Blender 5.2+
- Исправлена ошибка установки `module loaded with no associated file` на Blender 5.2
- Аддон теперь корректно распознаётся как расширение через `bl_extension_ops.py`

## 2.0.0 — 2026-08-31

### Архитектура
- Аддон разделён на 6 модулей: `core`, `shadow`, `compositor`, `materials`, `operators`, `ui`
- Чистая структура зависимостей без циклических импортов
- Каждый модуль: 188–1119 строк (вместо 3648 в одном файле)

### Возможности
- Послойный композитинг с автоматической сборкой нод
- Туман (fog) через unified mist-маску с per-layer контролем
- Атмосферный блюр по глубине
- Камерная глубина резкости (DOF)
- Glare / Bloom (Bloom, Fog Glow, Streaks, Ghosts)
- Дисторсия объектива и хроматическая аберрация
- Тени (Cast / Receive) с прокси-объектами
- Редактирование материалов (экспозиция, контраст, насыщенность, тон)
- 1-Click EXR рендер + сборка компа из файлов
- Drag & drop перестановка слоёв
- Compositor-панель в Node Editor
